# Portfolio Kain McKancy La Reine

## 🌟 Project Overview
**Mini Magnetic Charger Website**  
A responsive HTML/CSS/JavaScript implementation for a magnetic wireless charger product.

🔗 [Live Preview](https://kainlareine.nl)  
⚙ **Built with**: React, Tailwind CSS, EmailJS

---

## 🎯 Features
### Core Functionality
- 🖥️ **Fully Responsive** design adapting to all screen sizes
- 📱 **Mobile-First** approach for optimal mobile experience
- ✉️ **Functional Contact Form** with EmailJS integration
- 🔄 **Interactive UI Elements** with smooth animations

### Technical Highlights
- ⚛️ **React-Bootstrap** components for consistent UI
- 📂 **Centralized Content Management** via `content_option.js`
- 🚀 **Optimized Performance** with code splitting
- 🔍 **SEO-Friendly** markup structure

---

## 🛠 Installation & Setup

### Prerequisites
- Node.js (v14+)
- Yarn package manager

### Quick Start
```bash
# Clone repository
git clone https://github.com/kainlareine/magnetic-charger.git

# Install dependencies
yarn install

# Run development server
yarn start

# Build for production
yarn build
